## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.7-x64-setup.msi`**, or let RDM install it by itself (the "Version 0.3.7 available" card) |
| Debian / Ubuntu | `rdm_0.3.7-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.7-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Edge / Brave / Opera / Vivaldi… | from RDM (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox / Waterfox / LibreWolf / Floorp / Zen… | from RDM, or `rdm-firefox.xpi` (extension 0.4.5) |

## Changed
