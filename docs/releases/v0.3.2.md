Firefox and Waterfox hand downloads to RDM before they start, the extension keeps itself up to date there, and RDM asks before starting what the browser sends.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.2-x64-setup.msi`** — or let RDM 0.3.1 install it by itself (the "Version 0.3.2 available" card) |
| Debian / Ubuntu | `rdm_0.3.2-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.2-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Brave / Opera / Edge | from RDM (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox / Waterfox | from RDM, or `rdm-firefox.xpi` (extension 0.4.2) |

## New

- **Firefox, Waterfox, LibreWolf**: RDM takes a download over as soon as the server answers, before the browser fetches it — no more half-downloaded copy left in the browser, small files included.
- **The Firefox extension updates itself** from the latest RDM release (`updates.json`).
- **Confirm downloads from the browser**: RDM comes to the front and asks "Download / Cancel"; when a file of that name already exists, "Keep both" or "Replace". "Don't ask again" turns it off; it can be turned back on in the settings.

Thanks to Flybrow for these changes.
