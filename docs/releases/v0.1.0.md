First public version of **RDM**, an open-source download manager for Windows 11 and Linux.

![RDM](https://raw.githubusercontent.com/vincentxjoubert-lang/rdm/main/docs/screenshots/dashboard-dark.png)

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.1.0-x64.msi`**: double-click, installed for your account, no administrator rights |
| Ubuntu 26.04 | from the source code: `sh install-ubuntu.sh` (icon in the applications, starts at login) |
| Debian / Ubuntu | `rdm_0.1.0-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.1.0-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh --autostart` |
| Firefox | `rdm-firefox.xpi` |
| Chrome / Brave | `rdm-chrome-extension.zip`: extract, then "Load unpacked" |

The Linux files are added automatically by the continuous integration a few minutes after publication.

## What's new

- **New interface**: dashboard with the live speed and last minute's chart, a card per download (colour per category, animated progress), dark and light themes, Inter font, Phosphor icons, in-window notifications, **Ctrl+F** to search.
- **Built-in VirusTotal analysis** of completed files up to 650 MB: lookup by fingerprint first (nothing is uploaded if the file is known), otherwise upload, then a full report inside RDM. A free API key to enter once.
- **Updates**: RDM detects new versions published here; on Windows it installs them in one click.
- **New icon** for the application, the Start menu, the notification area and the extension.
- **One-command Ubuntu installation** (`install-ubuntu.sh`) and an **MSI installer** for Windows.

## Speed

- Sparse files on Windows: NTFS no longer fills the file with zeros before each distant segment (the disk wrote everything twice and connections waited).
- No Windows 11 "EcoQoS" throttling when RDM is in the background; network and disk threads at higher priority.
- The receive loop no longer takes a lock shared by all 64 connections for every packet.
- The list is written to disk at most twice a second, away from the interface (instead of a full rewrite on every change).

## Fixes

- **Linux: RDM refused to close or to leave the taskbar.** The window is now really closed when closed to the notification area, *Quit* works in every situation, and on Wayland the interface no longer freezes when the window is minimized.
- **Windows: RDM used 100% of a core in the notification area.** 0% now, and 46 MB of memory instead of about 110 MB.
- **Chrome / Brave extension: the "'background.scripts' requires manifest version of 2 or lower" error** is gone (a manifest per browser).
- Resuming after a cut: resume point every 20 s; a crash, a shutdown or a logout no longer restarts a download from zero (Linux: clean stop on SIGTERM).
- Extension: a small file the browser already finished is no longer downloaded a second time; in private browsing and Firefox containers, the right session's cookies are used; the player iframe's referrer is passed on.
- File names given by the server: `filename="a;b.zip"` and `Filename=` (capitalized) are now read correctly.
- Atomic audio/video merge: no more truncated file under the final name when it fails.
- Dynamic segment splitting: fixed a rare race that could move a segment's end.
- No more zombie process after "Open file" on Linux; the file manager is opened off the interface thread.
- Shutdown: no new downloads started while closing; a long SHA-256 computation no longer delays the exit.

## Checks

Clippy without warnings and unit tests on Windows and Linux; real window and notification-area scenarios on Windows 11, X11, Weston and Sway; real downloads checked by SHA-256 (1 to 64 connections, brutal cut then resume); Ubuntu installer tested end to end on Ubuntu 26.04.1; MSI installed then uninstalled.
