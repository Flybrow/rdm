Première version publique de **RDM**, gestionnaire de téléchargements open source pour Windows 11 et Linux.

![RDM](https://raw.githubusercontent.com/vincentxjoubert-lang/rdm/main/docs/screenshots/tableau-de-bord-sombre.png)

## Installer

| Système | Fichier |
|---|---|
| Windows 10 / 11 | **`RDM-0.1.0-x64.msi`** : double-clic, installé pour votre compte, sans droits administrateur |
| Ubuntu 26.04 | depuis le code source : `sh install-ubuntu.sh` (icône dans les applications, démarrage automatique) |
| Debian / Ubuntu | `rdm_0.1.0-1_amd64.deb` : `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.1.0-1.x86_64.rpm` : `sudo dnf install ./rdm-*.rpm` |
| Linux (autres) | `rdm-linux-x64.tar.gz` : extraire, puis `sh install.sh --autostart` |
| Firefox | `rdm-firefox.xpi` |
| Chrome / Brave | `rdm-chrome-extension.zip` : extraire, puis « Charger l'extension non empaquetée » |

Les fichiers Linux sont ajoutés automatiquement par l'intégration continue quelques minutes après la publication.

## Nouveautés

- **Nouvelle interface** : tableau de bord avec la vitesse en direct et la courbe de la dernière minute, cartes par téléchargement (couleur par catégorie, progression animée), thèmes sombre et clair, police Inter, icônes Phosphor, notifications dans la fenêtre, **Ctrl+F** pour chercher.
- **Analyse VirusTotal intégrée** pour les fichiers terminés de 650 Mo au plus : recherche par empreinte d'abord (rien n'est envoyé si le fichier est connu), sinon envoi, puis rapport complet dans RDM. Clé API gratuite à saisir une fois.
- **Mises à jour** : RDM détecte les nouvelles versions publiées ici ; sous Windows il les installe en un clic.
- **Nouvelle icône** pour l'application, le menu Démarrer, la zone de notification et l'extension.
- **Installation Ubuntu en une commande** (`install-ubuntu.sh`) et **installateur MSI** pour Windows.

## Vitesse

- Fichiers creux (*sparse*) sous Windows : NTFS ne remplit plus de zéros le fichier avant chaque segment éloigné (le disque écrivait tout deux fois et les connexions attendaient).
- Pas de bridage « EcoQoS » de Windows 11 quand RDM est en arrière-plan ; threads réseau et disque en priorité supérieure.
- La boucle de réception ne reprend plus un verrou partagé par les 64 connexions à chaque paquet.
- Liste enregistrée sur disque au plus deux fois par seconde, hors de l'interface (au lieu d'une réécriture complète à chaque changement).

## Correctifs

- **Linux : RDM refusait de se fermer ou de quitter la barre des tâches.** La fenêtre est maintenant réellement fermée quand on la ferme vers la zone de notification, « Quitter » fonctionne en toutes circonstances, et sous Wayland l'interface ne se fige plus quand la fenêtre est minimisée.
- **Windows : RDM consommait 100 % d'un cœur dans la zone de notification.** 0 % désormais, et 46 Mo de mémoire au lieu d'environ 110 Mo.
- **Extension Chrome / Brave : l'erreur « 'background.scripts' requires manifest version of 2 or lower »** a disparu (manifeste propre à chaque navigateur).
- Reprise après coupure : point de reprise toutes les 20 s ; un plantage, une extinction ou une fermeture de session ne fait plus repartir un téléchargement de zéro (Linux : arrêt propre sur SIGTERM).
- Extension : un petit fichier déjà terminé par le navigateur n'est plus téléchargé une seconde fois ; en navigation privée et dans les conteneurs Firefox, les cookies de la bonne session sont utilisés ; le referer de l'iframe du lecteur est transmis.
- Noms de fichiers fournis par le serveur : `filename="a;b.zip"` et `Filename=` (majuscule) sont désormais bien lus.
- Fusion audio/vidéo atomique : plus de fichier tronqué sous le nom final en cas d'échec.
- Découpage dynamique des segments : correction d'une course rare qui pouvait déplacer la fin d'un segment.
- Plus de processus zombie après « Ouvrir le fichier » sous Linux ; ouverture du gestionnaire de fichiers hors du fil de l'interface.
- Arrêt : plus de nouveaux téléchargements démarrés pendant la fermeture ; un calcul SHA-256 long ne retarde plus la sortie.

## Vérifications

Clippy sans avertissement et tests unitaires sous Windows et Linux ; scénarios réels de la fenêtre et de la zone de notification sous Windows 11, X11, Weston et Sway ; téléchargements réels vérifiés au SHA-256 (1 à 64 connexions, coupure brutale puis reprise) ; installateur Ubuntu testé de bout en bout sur Ubuntu 26.04.1 ; MSI installé puis désinstallé.
