Clearer settings, any Chromium- or Firefox-based browser, and RDM asks before touching a file that is already there.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.6-x64-setup.msi`**, or let RDM install it by itself (the "Version 0.3.6 available" card) |
| Debian / Ubuntu | `rdm_0.3.6-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.6-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Edge / Brave / Opera / Vivaldi… | from RDM (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox / Waterfox / LibreWolf / Floorp / Zen… | from RDM, or `rdm-firefox.xpi` (extension 0.4.5) |

## New

- **Settings in tabs**: General, Downloads, Browser, Security, Advanced — from what everyone uses to the expert settings, each tab with its own "Restore this tab's defaults". Nothing changes in your saved settings.
- **"If the file already exists": Ask**, the new default. RDM comes to the front and lets you keep both files or replace the old one — for browser downloads, and for pasted or copied links too (asked once the server gave the name, before anything is written). Settings saved with another choice keep it.
- **Any Chromium- or Firefox-based browser**: the extension window lists every browser Windows registers as installed (Vivaldi, LibreWolf, Floorp, Zen, Thorium…), and **Add a browser…** picks a portable one by its program. On Linux, the connector is registered for any browser found by its profile folder.
- **Remove the extension** from RDM's extension window: the extension uninstalls itself at its next check-in.
- The tab RDM opened to install the extension closes by itself once the extension is installed.
- **Progress bar split by connection** while a download runs: each piece at its place in the file.
- The title bar follows RDM's colours on Windows 11.
- The download confirmation says what "Don't ask again" does, and what downloading unconfirmed risks.
