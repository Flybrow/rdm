A security release: RDM's link with the browser is locked to your account, your cookies and logins stay on their site, and a few bugs that could lose or block files are fixed.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.1-x64-setup.msi`** — or let RDM 0.3.0 install it by itself (the "Version 0.3.1 available" card) |
| Debian / Ubuntu | `rdm_0.3.1-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.1-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Brave / Opera / Edge | from RDM (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox / Waterfox | from RDM, or `rdm-firefox.xpi` |

## Security

- **The local bridge only obeys you.** Programs talking to RDM (the browser connector, the installers) now prove they run under your account with a secret RDM renews at each start, and check that the program on RDM's port is really yours before sending anything. Another account of the computer can no longer drive RDM, nor pose as it to collect the cookies the extension sends.
- **Cookies and logins stay on their site**: a video stream (HLS) or a separate audio track pointing to another site's servers no longer receives them.
- **Local network protection** now also covers names that resolve into your network (DNS rebinding included). Downloads from your own NAS or router keep working.
- **File names** can no longer disguise their type with text-direction characters (`facture‮fdp.exe` shown as a PDF); more reserved Windows names are handled.
- On Linux the settings folder is private (0700). The VirusTotal key only goes to VirusTotal.
- Releases are built with pinned tools and signed in an isolated job.

## Fixes

- With "Overwrite", removing a download that had not started (or failed at once) deleted your existing file of that name.
- Removing a download could delete an unrelated file whose name started the same way.
- A server answering a whole-file request with the whole file (200) made the download hang.
- A download resumed later continues only if the file has not changed on the server; otherwise it starts over instead of mixing two versions.
- "Delete the file" now asks for confirmation.
- Captured formats may be written one per line.
- The Windows uninstaller removes the "start with the system" entry.
