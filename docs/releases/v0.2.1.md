Automatic updates repaired, a Desktop shortcut, and the fixes of a full audit.

## From RDM 0.1.0 or 0.2.0: one manual installation, once

The automatic installation of those versions was broken: **RDM closed and nothing happened**. It cannot be repaired remotely. To move to 0.2.1:

1. download **`RDM-0.2.1-x64-setup.msi`** below (RDM's "Version available" card opens this page);
2. double-click it: the installer **closes RDM itself**, installs the new version and starts it.

Running downloads resume where they were. Later updates are **one click** from RDM again.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.2.1-x64-setup.msi`**: double-click, installed for your account, no administrator rights, Start menu and Desktop shortcuts |
| Ubuntu 26.04 | from the source code: `sh install-ubuntu.sh` |
| Debian / Ubuntu | `rdm_0.2.1-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.2.1-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh --autostart` |
| Chrome / Brave / Opera / Edge | **from RDM** (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox | **from RDM**, or `rdm-firefox.xpi` |

## Updates: completely redone

- **Cause of the problem**: RDM started the installation through PowerShell without a console, which PowerShell 5.1 silently refuses. RDM closed, and neither the installer nor the restart ran.
- **New way, without PowerShell**: RDM downloads the installer (with retries if the connection drops), **checks** it (size and SHA-256 published by GitHub, MSI format), then closes. An assistant — a copy of RDM — waits until it is really gone, installs (progress bar, log in the temporary folder) and starts RDM again.
- **Never closed without explanation**: if the installation fails, the assistant shows the reason, offers to try again and starts the current version. If the download fails, the card stays with a *Retry* button.
- **The installer closes RDM itself** before replacing its files (cleanly for recent versions, forcibly for old ones). Before, installing over a running RDM said "installation complete" but kept the old version until Windows restarted.
- A version published just before its installer was online is checked again after 15 minutes, instead of the next day.

## What's new

- **Desktop shortcut** (Windows, and Linux when the Desktop shows icons), removed on uninstall.
- `rdm --quit` cleanly closes a running RDM (used by the Windows and Linux installers, which start it again in its new version).

## Fixes (full audit)

- **Speed limit**: with a low limit, the many connections waited their turn so long that the server cut them ("timed out"). RDM now opens one connection per 256 KB/s allowed, and a slow but active transfer is no longer taken for a cut.
- **Start**: if RDM's local port is held by a program that does not answer (a stuck RDM), RDM waits a few seconds then explains, instead of closing silently.
- A link already in the history was not added if it was sent again within 5 seconds of the start.
- The temporary file of a refused update is deleted at once.
