RDM now speaks 16 languages, with automatic detection of the system language and a drop-down list in the settings.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.3-x64-setup.msi`**, or let RDM install it by itself (the "Version 0.3.3 available" card) |
| Debian / Ubuntu | `rdm_0.3.3-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.3-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Brave / Opera / Edge | from RDM (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox / Waterfox | from RDM, or `rdm-firefox.xpi` (extension 0.4.3) |

## New

- **16 languages**: English, French, Spanish, German, Italian, Portuguese, Dutch, Polish, Russian, Ukrainian, Turkish, Vietnamese, Indonesian, Chinese (Simplified), Japanese, Korean. RDM follows the system language; **Settings → Language** has a drop-down list.
- **The browser extension is translated too** (it follows the browser's language).
- Chinese, Japanese and Korean text is drawn with an embedded font (the program is about 19 MB bigger); Latin, Cyrillic and Vietnamese letters are now covered by the main font.

Not yet supported: right-to-left and complex scripts (Arabic, Hebrew, Hindi, Thai), which the UI toolkit cannot display correctly. Translations are machine-written and not yet reviewed by native speakers: corrections are welcome in `crates/app/locales/`.
