YouTube videos that YouTube refused to hand over directly ("anti-bot token required") can now be downloaded from the ⬇ button.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.4-x64-setup.msi`**, or let RDM install it by itself (the "Version 0.3.4 available" card) |
| Debian / Ubuntu | `rdm_0.3.4-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.4-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Brave / Opera / Edge | from RDM (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox / Waterfox | from RDM, or `rdm-firefox.xpi` (extension 0.4.4) |

## New

- **YouTube module (anti-bot token)**: when YouTube refuses the direct links, the ⬇ menu offers to install RDM's YouTube module once (about 300 MB, in the user's folder, no administrator rights): yt-dlp, Deno and bgutil, which generates YouTube's anti-bot token locally. Each file is checked against its published SHA-256. The qualities then appear in the menu as usual, verified to the last byte, and RDM downloads them at full speed.
- When no method works, the menu now says why (the last refusals), instead of a bare message.

DRM-protected videos (paid films) remain unsupported. A network YouTube blocks outright (some VPNs) may still be refused.
